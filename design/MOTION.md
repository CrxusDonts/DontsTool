# DontsTool 动效规范

浅色交互稿与本项目的原生启动器布局配合使用。动效解释“出现、选择、执行、反馈”，以短时长为主。所有系统操作均为浏览器内演示，不读取真实剪贴板，不修改系统设置，不调用系统翻译。

| 触发 | 变化 | 时长 | 缓动 |
| --- | --- | --- | --- |
| 呼出面板 | 透明度 0→1，向上移动 8px，缩放 .985→1 | 220ms | cubic-bezier(.16,1,.3,1) |
| Esc / 收起 | 淡出，向下移动 4px，缩放 1→.99 | 140ms | cubic-bezier(.4,0,1,1) |
| 鼠标悬停 | 结果行底色轻微变化 | 100ms | ease-out |
| ↑↓ 选择 | 选中底色与边框切换，轻微淡入反馈 | 140ms | ease-out |
| 输入筛选 | 取消上次动画，结果淡入并上移 3px | 120ms | ease-out |
| 多行更新 | 每行延后 14ms，最多延后 56ms | 14–56ms | 同上 |
| 复制反馈 | 轻量 Toast 淡入并上移，停留后淡出 | 180 + 1400 + 140ms | 快入、短停、淡出 |
| 设置开关 | 滑块移动，轨道颜色变化 | 160ms | cubic-bezier(.22,1,.36,1) |
| 翻译演示进行中 | 显示状态与转圈，完成后显示译文反馈 | 演示等待 700ms | 转圈 800ms linear |

## 预览方式

打开 [index.html](index.html)，选择场景，使用顶栏的“重播呼出”和“收起 / 呼出”。进入面板后按 ↑↓、Enter、⌘ Enter 或 Esc；点击 JSON 操作行可看复制反馈；点击翻译主项可看进行中与完成状态；设置页可点击开关。

搜索输入框会在示例结果内筛选，用于观察列表更新；不是对本机应用和文件的真实查询。动作反馈前缀“演示”用于说明此边界。

## 减少动态效果

自动遵循系统的 prefers-reduced-motion。预览入口还提供临时“减少动态效果”复选框，便于比较：移除位移、缩放和逐行延后，动画与过渡缩短至 1ms，保留清晰的选中、焦点与完成反馈。它只影响这份设计稿。

## 原生实现约束

不通过不断改变模糊半径、阴影或布局尺寸做动画。面板内容、结果选中与反馈层分别控制；输入与键盘导航不等待动画完成。新输入覆盖旧输入时取消旧动画；反复呼出、Esc、重播不应叠加动效。隐藏后恢复前台应用的焦点，沿用现有面板行为。

执行结果、错误和权限状态需由实际服务返回。不要用固定时长动画代替真实完成信号；这里的 700ms 仅用于翻译过程的视觉演示。
