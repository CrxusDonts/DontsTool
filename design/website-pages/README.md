# 系统子页面设计参考

基于既有环境启动器，使用 Stitch 编辑并导出原始 HTML 和截图。`index.html` 是无外部依赖的离线派生演示，支持 `ops avatar`、`ops avatar management`、`ops avatar management prod`、方向键选择及 Enter 地址预览，不会实际打开网址。

`stitch-reference.html` / `stitch-reference.png` 保留原始生成结果，可能依赖外部 CDN；`stitch-export.json` 记录来源、提示词及返回建议。离线稿用 TEST 蓝色、PROD 红色对齐原生实现，原稿配色保持原样。
