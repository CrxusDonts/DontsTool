# 启动器交互预览

直接打开 [index.html](./index.html)。页面完全离线，样式、脚本与图标都在同一个文件中，不依赖字体服务、图片服务或脚本 CDN。

这是交互稿，实际结果以原生 App 为准。所有演示执行只显示带有“交互预览”的提示，不打开应用或网页，不访问系统剪贴板，不发送远程请求。搜索结果、拼音别名和使用顺序均为页面内示例。

## 可以体验的交互

- 在面板外切换浅色、深色，重播唤起，或手动开启减少动态效果。系统开启减少动态效果时自动跟随。
- 搜索微信、终端、Visual Studio Code、Xcode 和文本工具，支持 `wx`、`zd`、`vscode` 等静态别名。
- 使用方向键或鼠标移动选择，单个选择底板在 54 像素高的结果行之间连续滑动。按回车或点击结果演示执行。
- 按 `⌘K` 或点击底栏“操作”展开操作浮层；方向键选择，回车演示。按 `Esc` 先收起浮层，再关闭面板；“重播唤起”可以重新显示。
- 切换最近使用、使用频率、名称排序，观察同一组示例结果的排列。
- 点击面板外的 JSON、链接、文本示例附加内容。面板仅显示类型与字符数，搜索框变为操作筛选；原文不会成为搜索词。点击附加内容右侧的移除按钮返回普通搜索。
- JSON 只推荐 JSON 工具；链接推荐浏览器与 URL 编解码；普通文本推荐 Base64 编解码及翻译。工具入口仅表示带入原文，不表示已经转换或翻译。

## 视觉与动效

默认在 1280 × 900 的视口中居中显示 700 × 480 的面板。外部预览控件不属于产品界面。较窄视口会缩小面板宽度，保留结果滚动与键盘操作。

面板使用 18 像素外圆角、72 像素搜索头、54 像素结果行及 38 像素底栏。主配色为石墨 `#252C2F`、暖灰 `#EEECE6`、薄荷绿 `#6CD4BD`，浅色模式强调色为 `#18786F`，字体使用系统字体。

唤起和关闭采用 200 毫秒淡入淡出与 8 像素位移；选择底板使用 160 毫秒连续移动；操作浮层使用 140 毫秒短展开。系统或手动开启减少动态效果时去除位移过渡。
