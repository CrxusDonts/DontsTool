# 知识库插件设计

两张屏幕：轻量入口与独立文章窗口。沿用 DontsTool 暖灰工作台设计系统。

- `index.html`：本地浏览入口，可切换两张设计。
- `home.html`：搜索文章，保留快速收集和收集箱三个入口。
- `article.html`：完整文章在独立 macOS 窗口中编辑，正文为唯一主编辑区。
- `original/`：Stitch 原始 HTML 与截图。
- `source.metadata.json`：项目、屏幕、设计系统、生成提示词与本地处理记录。

这是视觉及交互参考，不代表原生窗口、连接、搜索、保存或编辑器已经接入。

实际产品应复用 DontsKb 现有 React/Tiptap 编辑器和保存保护：保留结构化内容、附件、版本校验、未保存内容离开保护；不要重新实现一套简化编辑器。置顶属于 DontsTool 原生窗口能力，保存状态由真实编辑器状态驱动。搜索结果打开独立文章窗口，快速收集与收集箱沿用现有知识库数据能力。

原始输出保留在 `original/`；本地 HTML 的任何规范化或交互模拟均记录在来源元数据中。
