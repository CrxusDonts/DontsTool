# DontsTool 工具窗口 v2：风格依据

用户反馈：纯白界面缺少设计感。2026-10-18 暂停当前原生界面外观实施，先重做可评审设计稿；功能内核保留。

## 实际参考

- Raycast Notes：https://www.raycast.com/core-features/notes — 轻量独立窗口、紧凑操作、材质和边界的层次；不照搬其浮层行为。
- DevUtils JSON：https://devutils.com/docs/json-formatter-validator/ — 输入/输出编辑区、语法高亮和错误定位的功能布局；不引入侧栏或额外工具。
- Zed Theme Builder：https://zed.dev/theme-builder — 窗口表面、面板、编辑器、选区、状态各自独立的视觉角色。

## 这次改什么

- 标题栏与工具栏构成统一的窗口框架；主模式放在标题区，常用动作有明确主次。
- 编辑区作为有内边距的工作区域，配独立面板标题、行号槽、选区和聚焦边界，保留真正的大编辑面积。
- 使用暖灰或石墨的多层表面，避免整窗同一颜色；强调色只用于主动作、当前模式和聚焦。
- 对比区域的差异摘要和列表具备真实信息层级；颜色之外同时使用图标与文字。
- 悬停 100–120ms，模式指示器 160ms，复制反馈 140ms；不动画化输入文本，不添加持续装饰动画，支持减少动态效果。
- 两套稿使用相同 JSON 内容，以便比较整体层次而非样例差异。

设计稿是 HTML 参考，不能作为原生实现验证。现有白底原型未完成最终验证，也不是最终交付界面。
