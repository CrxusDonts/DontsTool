# DontsTool Tool Workspaces v2
Native macOS utility windows, not a website. Standard traffic-light titlebar and functional keyboard-first layout. Window content 1040x700, min 760x520. No sidebar, no dashboards, no promotional headings, no fake metrics. Use native system UI font (-apple-system, PingFang SC), 12–13px interface text, 13px SF Mono editor at 21px line height. Restrained crafted hierarchy: window shell, toolbar, inset editor wells, gutter, selection, inline status. Editor panels have 12px exterior breathing room, 10px panel corners, a thin outline and a very subtle inset shadow; no nested stacks of cards. Window perimeter corners 14px. Main controls 6px corners, 30px tall. Typography and spacing are primary hierarchy. Do not render a duplicate icon beside every heading. Chinese labels, short precise copy. Changes in states use 120–160ms transitions and reduced-motion overrides.
Warm stone / linen daylight theme. Outer desktop #D9D8D2. Window shell #E7E5DF, unified titlebar #DEDCD6, toolbar #EAE8E2, work area #EFEEE9, editor #F7F5F0 (never pure white), gutter #EEEBE4. Distinct tonal surfaces, not an all-white sheet. Main text #252B2D, secondary #66716E, hairline #D1D1C9. Refined teal primary #18786F, selected mode #DCEAE3, focused editor border #55988C. Syntax keys muted teal, strings terracotta #A65B3E, numbers #765CAD. Added green tint, deleted terracotta tint, changed amber tint. Native tactile controls, restrained shadow, no gradient backgrounds, no saturated purple or blue template.
