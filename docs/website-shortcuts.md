# 网址快捷入口

在「DontsTool 设置 → 网址快捷入口」维护常用网址。每个分组有一个前缀，每个系统有简称、显示名称和可选别名，可以配置单个网址，也可以配置 test、prod 等多个环境地址。

- 输入 `gh` 列出代码仓库分组，方向键选择，回车打开默认浏览器。
- 输入 `gh a`，精确简称优先；`gh 订单服务` 可按别名匹配。
- 在分组内也可按显示名称模糊过滤；没有匹配时留在启动器显示提示，不转到公共搜索。
- 不带前缀时也可搜索已配置的名称、简称和别名。空查询提供分组入口，回车填入该前缀。
- 输入 `ops 订单` 列出订单系统的所有环境；`ops 订单 test`、`ops 订单 prod` 筛选对应环境，也可输入 `pro` 等环境前缀或已配置的环境别名。
- 多环境结果会显示环境标签和实际地址；省略环境时同时展示候选，按方向键选择后，回车打开当前选中的地址。
- 输入过程只查询本机配置；仅执行「打开网址」操作时打开浏览器。

## 手动维护

「添加分组」填写前缀与名称，再在分组中「添加系统」。每个系统可配置多个别名，每行一个。编辑系统时选择「单个网址」或「多个环境」；多环境下逐个填写环境简称、名称、完整地址和别名，支持自定义 dev、staging 等环境。切换模式会保留当前表单内暂存的输入，保存只采用当前模式。系统行「编辑」修改条目，右键菜单可删除系统；分组菜单可编辑、删除分组。删除前有确认。

前缀以英文字母开头，可含数字、`-` 和 `_`，最多32位，不区分大小写。自定义 `gh` 接管内置 GitHub 搜索；删除该分组后恢复原有行为。`json`、`kb`、`tr`、`g` 等其他内置前缀不可占用。简称不含空格；同组内简称和别名经大小写、全角半角归一化后不可重复。精确简称优先于精确别名和显示名称，变更输入会重新选择第一条；同一查询的后台刷新保留手动选择。

支持完整 `http://` 和 `https://` 网址，包括公司内网域名、IP、端口、路径、查询参数和片段。不拼接域名或猜测路径，也不预检网址是否可达；VPN、登录和站点权限仍由浏览器及网络环境处理。

## 系统子页面

在系统编辑器内「添加子页面」，填写页面简称、显示名称、路径和可选别名。例如 Avatar 的 management 页面路径为 `/admin/management`，可添加 `管理` 和 `managment` 别名：

- `ops avatar` 列出首页与所有子页面，首页优先。
- `ops avatar management` 列出管理页的各环境。
- `ops avatar management prod` 只显示生产管理页，回车打开。
- `ops avatar prod` 仍打开生产首页；也可明确输入 `ops avatar home prod` 或 `ops avatar 首页 prod`。

路径以单个 `/` 开头，从站点根目录解析。例如基础地址为 `https://avatar.company.example/base?old=1`，`/admin/management?tab=users#top` 最终得到 `https://avatar.company.example/admin/management?tab=users#top`；不追加原有 `/base`，不继承旧查询或片段。路径支持已编码的查询与片段，也可直接填写完整 HTTP(S) 地址，表示所有环境共用该页面地址。

某个环境的页面地址特殊时，展开「环境特殊网址」，为该环境填写完整 URL。未覆盖的环境继续使用通用路径；如果不填通用路径，必须覆盖所有环境。环境被删除或改名后，旧覆盖仍保留并显示待修复项，保存前需修正或删除；不会静默丢弃。单地址模式直接用页面路径或完整 URL，不使用环境覆盖。

页面简称不含空格；每系统内的页面简称/别名按大小写、宽度及空白归一化后不可重复。`home`、`首页` 是保留的首页入口。完整系统简称/别名优先，之后页面精确匹配优先于同名环境；不存在的页面或环境不会回退首页或公共搜索。

## JSON 批量配置

「JSON 配置」展示和手动编辑相同的数据，支持原生撤销、查找、行号与语法颜色。点击“取消”退出未保存的编辑时，会询问是否放弃。

「导入…」读取 UTF-8 JSON 后先打开编辑器供检查，不立即修改已有配置。保存会替换全部分组，编辑器展示当前和待保存的分组、系统、子页面和地址数量；只需增加少量条目时可先导出或在现有 JSON 上编辑。无效 JSON、未知字段、重复前缀/简称/别名、非 HTTP(S) 网址、网址内账号密码均阻止整份保存；不会部分导入。导出使用标准文件保存对话框。

[示例 JSON](examples/website-shortcuts.json) 使用虚构域名，请替换为实际地址后再保存。`version: 3` 新增子页面；原有 `version: 1` 单网址和 `version: 2` 多环境配置仍可直接使用，手动保存子页面时升级为3。`groups` 是分组数组，组内 `items` 是系统数组。每个系统填写 `url` 或非空 `environments` 数组，二者只能选一个。每个环境包含 `key`、`url`，可选 `name` 和 `aliases`；省略名称时显示环境简称的大写形式。`aliases` 可省略，提供时必须是字符串数组。

页面数组 `pages` 包含 `key`、`name`、`path` 和可选 `aliases`、`urls`。`urls` 是环境简称到完整网址的对象，仅能使用系统已配置的环境简称；不能使用环境别名。未填写的 `aliases`、`urls` 分别按空数组、空对象处理，显式 null 会被拒绝。

环境简称以英文字母开头，可含数字、`-` 和 `_`，最多32位。同一系统内的环境简称和别名不可重复。完整系统简称或别名精确匹配优先；否则最后一个词可作为环境筛选。没有匹配结果时不会跳转到其他环境。配置上限1 MiB、100个分组、5000个系统和5000个实际地址，每系统最多32个环境、100个子页面，系统、环境和页面各最多30个别名。5000个地址包括每个首页及每个页面在各环境下的最终地址。

配置只保存在本机 UserDefaults 的 `dontstool.websiteShortcuts` 数据项，重启保留。损坏配置不会被自动覆盖，可在 JSON 编辑器修复或导出原文。导入导出文件可用于手动备份或迁移；当前没有云同步、浏览器书签导入、URL 模板展开或环境变量插值。
