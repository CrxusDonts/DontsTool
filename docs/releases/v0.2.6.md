## 可配置搜索引擎与文件操作

- 设置的“搜索”页支持手动及 JSON 配置搜索引擎、快捷词、网址模板、启停和默认选择。内置引擎可以编辑，旧默认选择会保留。
- 输入“快捷词 搜索内容”调用对应引擎；只输入快捷词或搜索引擎名称，可回车补全快捷词继续输入。保存后立即更新路由，中文与特殊符号自动编码。
- 快捷词与现有功能、网址分组冲突时明确提示；保留既有 gh 网址分组接管内置 GitHub 搜索的行为。无效 JSON 不覆盖已保存配置。
- 文件结果选中或悬停时直接显示“定位”和“复制路径”。⌘Enter 在访达中定位，新增 ⌘⇧C 复制完整路径，普通 Enter 继续打开文件。
- 文件结果底栏显示对应快捷键，复制反馈包含文件名。沿用现有深浅色样式与按钮动效；普通 ⌘C、中文组词和动作菜单不受新增快捷键影响。
