# 0.2.13

- 首页工具区升级为「最近工具」：所有内置工具（便笺、Google Chrome、结束进程、终端与访达、IDEA 项目、Gemini 提问及文本/翻译工具）均记录最近使用时间，按最近使用顺序优先排在前排，不足 8 个时用默认工具补齐 4×2 网格。
- 新增「终端与访达（Terminal Finder）」：支持 `tf` / `ft` / `term` / `终端` 按唤起前应用自动双向跳转（访达 ↔ Ghostty / Warp / iTerm2 / 系统终端等），支持 `tf ~/path` 直接打开目录，在「设置 → 工具」中可选默认终端，并打通文件搜索、快速打开与 IDEA 项目的 `⌘K`「在终端中打开」。
- 内置可搜索、可交互的「使用指南」：可在「设置 → 使用指南」、菜单栏「使用指南」或启动器输入 `help` / `?` / `帮助` 查看全功能触发词、用法示例与动态快捷键速查，支持点击「试一下」直接填入启动器。
- 优化 JSON 工作台粘贴体验：空白编辑器直接粘贴及粘贴 Markdown ` ```json ` 代码块时均可自动剥离围栏并格式化。

已安装旧版的用户可以在菜单里选择「检查更新」。
