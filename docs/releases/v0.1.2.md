# DontsTool v0.1.2

新增右键长按划词翻译：在其他应用选中文字，按住右键或双指按下触控板约 0.5 秒，在鼠标旁查看原文和译文。

- 复用一张浮动卡片，支持固定、复制译文、重试和打开原文编辑。
- 短按在松开时恢复原有右键；拖动、无有效选区或取词超时则放行普通操作。
- 校验鼠标所在应用及 AX 窗口，防止同一应用多个窗口间取错选区。
- 功能默认关闭，需在「设置 → 翻译」开启并授予辅助功能权限。
- 使用已配置的 Responses 兼容翻译 API；只在触发翻译时发送选中文字，不自动复制、不读取剪贴板、不截图或 OCR。

macOS 26+，Universal 包含 Apple Silicon 和 Intel。应用使用 ad-hoc 本地签名，未经 Apple 公证；安装与首次打开方式见 [README](../../README.md#安装)。

核心及原生自动测试覆盖 225 项。跨应用取词依赖目标应用的辅助功能支持；真实触控板手势、不同 IDE 和多屏仍需本机验收，不能用自动化状态机测试代替。
