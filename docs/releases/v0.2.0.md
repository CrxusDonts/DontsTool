
## 本次更新

- **网址快捷入口**：支持「分组 → 系统 → 子页面 → 环境」，例如 `ops avatar management prod`；页面路径复用环境基础地址，也可为特定环境配置完整网址。支持手动编辑和 JSON 导入导出，兼容旧版配置。
- **应用搜索**：安装、移除和更新应用后自动刷新索引；支持拼音搜索，以及最近使用、使用频率和名称排序。
- **启动器与文件操作**：调整深浅色界面、选中反馈与窗口动效；文件搜索改为显式 `file` 入口，结果支持在访达中显示。显式粘贴可进入内容处理动作。
- **研发入口**：新增本地即时计算、网址/路径快速打开、IDEA 最近项目和 Gemini 新对话交接。Gemini 自动发送需要辅助功能权限，并取决于其当前界面的可访问性支持。
- **翻译**：修复右键长按检测与取词状态，短按保留原应用右键行为；支持已安装的系统翻译语言包，或使用自行配置的翻译 API。

本地验证覆盖 380 项 Core 测试、78 项原生测试，并实测子页面筛选及浏览器跳转。网址匹配与输入过程只读取本机配置，回车执行后才打开浏览器。
