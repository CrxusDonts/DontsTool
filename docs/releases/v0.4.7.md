## DontsTool v0.4.7

### 修复与优化

- **修复 JSON 对比与多编辑器快捷键焦点串台**：`WorkspaceTextView` 在处理快捷键前校验当前窗口 `firstResponder` 与输入法组词状态，避免在「右侧 JSON」或其他输入框中按 `⌘V`、`⌘C`、`⌘A` 时误触发「左侧 JSON」；同时为对比模式「粘贴」按钮补全 JSON 自动格式化、补全空编辑器第 1 行行号渲染，并为「代码」模式编辑器补充聚焦描边。
- **优化 JSON 结构树展开/收起响应速度**：重构 `ToolJSONTreeView` 与 `JSONAnalysis`，移除与折叠按钮冲突的双击等待手势，隔离行级 Hover 状态重绘并缓存扁平节点列表与路径查找字典，消除选中路径双向回写导致的重复展开卡顿，实现点击展开/收起即时响应。
