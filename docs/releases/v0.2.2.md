
## 本次更新

- **妙控板双指长按**：直接识别内置触控板和外接 Magic Trackpad 的双指持续接触，支持设备重连和睡眠恢复；鼠标右键短按保留原菜单。
- **可调唤起时间**：设置 → 翻译提供 300ms、500ms、1 秒、2 秒四档，鼠标与妙控板共用，修改立即生效并保存。
- **直接复制取词**：长按后向仍聚焦的源窗口发送 Cmd-C，只读取本次复制更新后的内容；不清空或还原剪贴板，复制的原文保留。复制失败不会误用旧内容；安全输入、窗口切换及超长选区会取消。
- **界面与图标**：更新启动器、工具窗口、设置、知识库和翻译卡片的视觉样式，加入正式应用图标。

本地已通过 391 项核心测试、112 项原生测试及 Universal 构建。用户确认妙控板手势可正常使用；自动回归覆盖四档计时、事件配对、复制内容新鲜度与窗口校验。各应用对 Cmd-C 的支持及配置的大模型服务连通性取决于实际环境。
