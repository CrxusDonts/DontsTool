# 0.2.12

- 新增「结束进程」工具：支持通过 `kill` / `kp` / `进程` 按进程名、PID 或 `:端口` 查找运行中的进程，支持优雅结束（`SIGTERM`）、强制结束（`SIGKILL`）、结束全部同名进程、复制 PID/命令以及在访达中显示程序位置。
- 新增「Google Chrome」工具：支持通过 `chrome` / `ch` 统一搜索已打开标签页、多 Profile 书签和浏览历史，支持 `tab` / `tabs` / `标签页` 专搜并切换或关闭标签页、`bm` / `书签` 专搜书签，以及快捷新建标签页、无痕窗口与复制网址/Markdown 链接。
- 为 Hardened Runtime 发布包配置 Apple Events 自动化权限声明，以便安全读取和控制 Chrome 标签页。

已安装旧版的用户可以在菜单里选择「检查更新」。
