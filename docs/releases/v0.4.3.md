# 0.4.3

- 修复跨版本设置同步乒乓死循环：应用远端设置、网址快捷入口、搜索引擎与便笺变更后，以本机落盘重导出后的规范化哈希更新本地同步基线，避免新旧版本字段差异触发来回覆盖互刷。
- 修复 WebSocket 自回声重复拉取并精简请求路径：忽略本机推送产生的自回声广播；实时连接就绪且基线对齐时，本地防抖编辑跳过前置 `/v1/sync/pull`，并通过服务端 revision 缺口自动兜底补拉。
- 优化实时心跳与图片附件缓存：同步防抖由 1.5 秒调整为 5 秒，长连接心跳改为 60 秒并在 401/403 鉴权失败时退避重连；本地记录已上云 blob 哈希并在拉取便笺时按 SHA-256 复用未变更图片，减少重复检查与下载请求（支持 409 缺失自动自愈重传）。

已安装旧版的用户可以在菜单栏或启动器更新提示中选择升级。
