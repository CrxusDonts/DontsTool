# 0.4.6

- 重构 JSON 工具窗口视觉与代码折叠体验：将行号栏扩展至 70pt，把原先过小的字符箭头替换为清晰可辨的 20×20pt 矢量折叠开关（带悬停态与蓝色折叠高亮），折叠代码块后方显示可点击的 `⋯ N 项 · M 行` 摘要胶囊；支持「全部折叠 / 全部展开 / 按层级（1–3 层）」快捷操作，并升级为 6 色语法高亮、轻量缩进参考线、当前行高亮与空气感行距。
- 新增结构树浏览、侧边大纲与 JSONPath 面包屑：顶部新增「代码 / 树形 / 对比」三段式切换；代码区顶部实时显示当前光标所处的 `$ › …` 可点击面包屑路径（支持一键复制路径），右侧可展开/收起实时联动、支持关键词过滤与大图标折叠的「结构树」大纲面板，「树形」模式支持全宽层级检索及一键复制路径/节点值或跳转定位。
- 升级 JSON 结构对比视图：双栏编辑器加入合法性状态圆点与一键「格式化两侧」（支持单步撤销），编辑器内同步绘制新增/删除/修改行高亮与左侧色条；底部差异表格新增「全部 / 新增 / 删除 / 修改」过滤胶囊与顶部上下差异步进导航器，大幅提升多差异定位效率。

已安装旧版的用户可以在菜单栏或启动器更新提示中选择升级。
