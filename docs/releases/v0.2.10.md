# 0.2.10

- 发布包正式启用 Apple Developer ID（`Q2K3CAKGG2`）签名与 Apple 官方公证，下载或一键安装后可直接通过 Gatekeeper 打开。
- 新增基于 Cloudflare（Worker + SQLite Durable Object + R2）的多端实时增量同步，并支持导出与恢复本地 `.zip` 完整备份包。
- JSON 工具编辑器新增对象与数组层级折叠，粘贴 JSON 时自动格式化。
- 移除内置知识库模块，并按 Core / Shell / UI 边界完成同步、便笺、设置、工具与划词监听模块的架构拆分。

已安装 0.2.7 及以上版本的用户可以在菜单里选择「检查更新」。
