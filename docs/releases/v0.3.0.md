# 0.3.0

- 升级为微内核 + 进程外 Sidecar 插件架构：主程序保持高频核心热路径精干，扩展插件以独立子进程（NDJSON over stdio）运行、支持权限声明与热重载。
- 新增「设置 → 插件」商店与 GitHub 插件源管理：默认内置官方插件仓库 `CrxusDonts/DontsTool-Plugins`，支持订阅自定义 GitHub 单插件仓、多插件合集仓或 `catalog.json` 链接；安装与更新前自动校验 SHA-256 与宿主版本要求，并弹出权限确认及跨源同名冲突提示。
- 结束进程（`kill`）、IDEA 项目（`idea`）、文件搜索（`file`）、Google Chrome（`chrome` / `tab` / `bm`）与终端与访达（`tf`）已外迁至官方插件仓库，升级后可在「设置 → 插件」一键安装全部推荐插件。

已安装旧版的用户可以在菜单里选择「检查更新」。
