# 0.4.0

- 升级统一「设置 → AI 与翻译」大模型底座：同时支持 OpenAI Responses、Gemini 原生 REST API 与 OpenAI Chat Completions 三种接口格式，翻译窗口、全局右键长按划词与 AI 插件共用配置，API 密钥仅存本机登录钥匙串（Gemini 严格使用 `x-goog-api-key` 请求头鉴权并自动过滤思考链）。
- 新增原生流式 AI 对话窗口与插件 `openAI` 能力：支持多窗口、置顶、Markdown 代码块一键复制、多轮追问与中文输入法组合态保护；空搜索框粘贴内容新增「问 AI」预填动作。
- 下线旧版依赖辅助功能自动化的 Gemini Mac 版提问；全新独立插件 `com.donts.quick-ai`（`ai` / `ask` / `问`）已同步发布至官方插件仓库 `CrxusDonts/DontsTool-Plugins`（`v1.1.0`），可在「设置 → 插件」一键安装，密钥不经过插件进程。

已安装旧版的用户可以在菜单栏选择「检查更新」。
