# 0.4.2

- 新增独立「设置 → 模型服务」页：支持保存多套大模型配置（OpenAI Responses、Gemini 原生 REST API、OpenAI Chat Completions），可分别为「默认模型」「翻译与划词」「AI 快问」指定不同模型，并支持一键测试连接与多端云同步（API 密钥仍仅保存在本机钥匙串，既有单配置自动无感迁移）。
- 全面整理设置页信息架构：「翻译」回归纯净的目标语言与划词设置；「搜索」并入应用索引并清理已失效的文件搜索重复开关；「通用」接管首选终端并去除重复快捷键列表；「工具」与「关于」同步精简。
- 加固插件安装器：对独立压缩包直链 `downloadURL` 支持自动回退识别根目录 `manifest.json`。

已安装旧版的用户可以在菜单栏或启动器更新提示中选择升级。
