# 0.4.5

- 新增配置同步冲突拦截与交互式 JSON Diff 解决：当多端并发修改、首次同步存在本机自定义配置，或检测到旧版本疑似清空模型配置/推送陈旧时间戳时，暂停覆盖该配置并挂起冲突（其余便笺与无冲突配置继续正常同步）；支持在设置页通过「按字段合并」、「完整差异（JSON Diff）定位」与「编辑合并 JSON 实时校验」三种视图自主决定采用云端、保留本机或应用合并结果。
- 新增配置覆写前本地历史快照与温和冲突提示：每次远端同步覆写或解决冲突落盘前，自动在本地留存最近 10 份配置 JSON 快照并支持预览与一键恢复；同时在菜单栏、设置侧边栏与同步设置页给出非侵入式冲突计数提示，并支持高版本未知设置字段透传与真实本地修改时间追踪。
- 升级同步服务端乐观锁校验：`POST /v1/sync/push` 支持可选 `baseRevision` 整批原子乐观锁与逐实体 `itemRevisions` 修订追踪，遇到远端版本推进时返回 409 并自动回退重拉转为本地冲突处理，完全向后兼容旧版客户端。

已安装旧版的用户可以在菜单栏或启动器更新提示中选择升级。
