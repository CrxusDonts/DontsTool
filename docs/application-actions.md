# 应用动作

自 `v0.3.0` 微内核插件化起，**Gemini 新对话**保留在微内核内置（在 **设置 → 工具** 开关管理），**IntelliJ IDEA 项目**已外迁为官方外部插件（在 **设置 → 插件** 安装管理）。

## Gemini 新对话（内置）

输入 `gm 问题` 或 `gemini 问题`，回车执行「新建并发送」。问题交给本机已安装的 Gemini Mac 应用，沿用其中已登录的账号，后续在 Gemini 窗口中继续对话。单独输入 `gm` 可只打开应用；带问题时的次操作同样只打开不发送。

- **应用检测**：按 bundle identifier 检查本机应用索引，不会把同名应用误认作 Gemini。**设置 → 工具** 中显示已安装、未安装或检测中；未安装时开关禁用，也不会提示申请辅助功能权限。显式输入 `gm` 而未安装时会给出安装提示，不误走网页搜索。
- **权限与隐私**：自动发送通过 Gemini 新对话路由和辅助功能控件执行，需要在 **设置 → 工具 → Gemini 自动提问** 授予辅助功能权限；仅打开应用无需此权限。此集成不使用 Gemini API 密钥，不把问题写入 URL、日志或剪贴板，输入过程不联网。
- **安全中止**：执行前检查未发送草稿并保留；确认新会话空白后才写入，核对完整问题与活动窗口后再发送。发送仅尝试一次，遇到未登录、加载中、窗口切换或控件变化即停止；按 `Esc` 或切换到其他应用可中止尚未发送的操作。
- **限制**：单次问题上限为 32768 UTF-16 单元。自定义网址分组前缀优先于内置关键词，如 `gm` 被占用可改用 `gemini`。

## IntelliJ IDEA 项目（已迁至官方插件仓库）

自 `v0.3.0` 起，IntelliJ IDEA 最近项目检索与打开功能已拆分为独立外部插件 `com.donts.idea-projects`，托管于官方插件仓库 [CrxusDonts/DontsTool-Plugins](https://github.com/CrxusDonts/DontsTool-Plugins)。

安装与使用方式：

1. 打开 DontsTool **设置 → 插件**，在默认的「DontsTool 官方插件仓库」中找到 **IDEA 项目**（或点击「安装全部推荐插件」）完成安装。
2. 安装后即刻热加载，在启动器中使用原有关键词与交互：
   - `idea`：列出最近打开的 IntelliJ IDEA 项目。
   - `idea kb`：按项目名称和路径片段模糊筛选。
   - `idea ~/路径/项目`：直接打开存在的本地项目目录，不要求先进入最近列表。
   - `⌘K`：在访达中显示、复制路径或在首选终端中打开（复用 **设置 → 工具 → 默认终端** 配置）。

插件以独立 `daemon` 子进程在后台读取 JetBrains 配置目录的 `recentProjects.xml` 并按文件指纹缓存，不扫描全盘、无需 IDEA 插件或辅助功能权限。插件协议、权限说明与更新管理见 [插件使用与开发指南](plugins.md)。
