# 应用动作

## Gemini 新对话

`gm 问题` 或 `gemini 问题`，回车执行“新建并发送”。问题交给现有 Gemini Mac 应用，使用其中已登录的账号，后续在 Gemini 继续对话。单独输入 gm 时可只打开应用；有问题时的第二动作同样只打开，不发送。

使用前按应用 bundle identifier 检查本机应用索引，不把同名应用当作 Gemini。设置 → 内置工具显示已安装、未安装或检测中；未安装时 Gemini 开关不可用，也不提示为它申请辅助功能权限。安装目录变化会触发应用索引更新，用户的启用偏好保留。显式输入 gm 而未安装时仍显示安装提示，避免把问题错误路由为网页搜索；执行前还会校验实际应用 bundle。

自动提问通过本机安装的 Gemini 新对话路由和辅助功能控件执行，需要为 DontsTool 授权辅助功能。设置 → 内置工具 → Gemini 自动提问可进入授权。仅打开应用不要求该权限。此集成不使用 Gemini API 密钥，不把问题放进URL、日志或剪贴板，输入时不联网。

执行前检查已有未发送草稿并保留；确认新会话空白后才写入，核对完整问题与活动窗口后点击发送。发送只尝试一次，遇到权限、登录/加载、窗口变化、改写或不可用按钮就停止。Esc 或切到别的应用可中止尚未发送的操作；已交给 Gemini 的问题由 Gemini 自身管理。

当前适配 Gemini Mac 的中文/英文输入框与本机验证版本的控件标识。应用界面改变时会停止操作，而不会猜测发送目标。单次问题上限为 32768 UTF-16 单元。自定义网址分组前缀优先级保持原有规则，若占用 gm 可使用 gemini。

## IntelliJ IDEA 项目

- `idea`：当前已安装版本的最近项目，按最近打开时间排列。
- `idea kb`：按项目名称和路径筛选。
- `idea ~/路径/项目`：打开存在的本地目录，不要求先进入最近列表。
- `⌘K`：在访达中显示、复制完整路径等操作。

从当前 IDEA 版本默认配置目录的 recentProjects.xml 后台读取，不扫描全盘。缓存依据文件修改时间、大小和inode；旧版本配置不混入，移动或删除的目录不会误启动。若使用自定义 IDEA 配置目录，可先用完整路径打开项目。

启动采用 JetBrains 官方支持的应用参数方式：给选定 IDEA 传入项目目录。IDEA 自身决定项目窗口行为，启动新应用实例不等同强制新项目窗口。无需 IDEA 插件或辅助功能权限，不修改 IDEA 配置。

上述两个入口均可在设置 → 内置工具禁用，普通全局搜索不调用它们。
