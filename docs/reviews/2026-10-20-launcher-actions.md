# 启动器常用操作与即时工具

- 日期：2026-10-20
- 范围：计算器/单位换算、快速打开网址或路径、⌘K 动作面板、应用/文件/网页动作扩展
- 状态：已实现并通过 Core 测试与本机界面验收

## 目标

参考 Raycast、uTools 的高频能力，在不改变既有边界的前提下补充：

1. 输入算式或单位换算时直接给出结果，回车复制。
2. 输入网址或已存在路径时直接打开，不经过网页搜索。
3. 任意结果按 `⌘K` 查看全部操作，而不是只能执行主操作和次操作。
4. 应用可退出、复制路径；文件可复制路径；网页结果可复制链接。

剪贴板历史仍然不做；所有复制动作只在用户明确选择后写入剪贴板，应用不监听剪贴板变化。算式与单位换算完全本地执行，不访问网络。

## 实现

### 计算器与单位换算

- `CalculatorEngine` 使用递归下降解析 `+ - * / ^ %`、括号、一元正负号、科学计数法、`pi`/`e` 和 `sqrt`、`abs`、`round`、`floor`、`ceil`、`ln`、`log`、`sin`、`cos`、`tan`。
- 单位换算先于表达式解析，支持长度、质量、温度、数据（1024 进制）、时间和速度；来源与目标必须属于同一类别。
- 普通单词、裸数字和日期形态不会触发计算器；`calc`、`=` 前缀可强制按算式处理。
- `CalculatorProvider` 在工具分组返回一条结果，主操作复制结果；关键词模式下输入无效时显示可返回的提示。

### 快速打开

- `QuickOpenParser` 识别 `http(s)://`、`www.`、`file://`、`~/` 和绝对路径；绝对路径必须存在。
- `QuickOpenProvider` 对网址提供打开与复制链接；对文件提供打开、Finder 显示与复制路径。
- 不识别裸域名，避免把普通搜索词误判成网址。

### 动作面板

- `LauncherPanelModel` 保存动作面板开关、选中项和选中动作；查询变化自动关闭动作面板。
- `SearchField` 增加 `⌘K` 路由；面板打开时方向键用于选择动作，回车执行，Esc 返回。
- `LauncherPanelView` 在右上角显示动作卡片，鼠标和键盘均可执行；底栏切换键位提示。
- `ItemAction` 增加可选 SF Symbol，动作面板据此显示图标。
- 应用动作：打开、Finder 显示、退出应用、复制路径。
- 文件动作：打开、Finder 显示、复制路径。
- 网页动作：打开、复制链接。
- 退出应用通过 `NSRunningApplication` 查找并请求终止；找不到运行实例时提示“应用未在运行”。

### 默认启用与迁移

`ProviderID` 新增 `calculator`、`quickOpen`。为已有用户增加一次性迁移，将两者加入默认启用集合；迁移完成后用户手动关闭不会被再次打开。

## 测试与验收

- Core 全量：251 项测试、36 个 suite 通过；新增覆盖表达式优先级、右结合幂、函数与错误、浮点格式化、六类单位换算、网址/路径解析、Provider 动作、设置迁移与动作面板状态。
- 原生/WebKit 集成：14 项测试、3 个 suite 通过。
- 真实界面（浅色/深色）：
  - 输入 `1+1` 显示结果 `2`，回车复制。
  - 输入 `10 km to mi` 显示 `6.2137119224 mi`。
  - 输入 `https://example.com` 显示“打开网址”。
  - 输入 `Calculator` 后 `⌘K` 显示四个应用动作；方向键移动到“复制路径”并回车，系统剪贴板得到 `/System/Applications/Calculator.app`。
- 界面验证使用独立 bundle ID 的临时 QA 副本和合成键盘输入，不修改已安装应用；正常用户的快捷键呼出流程不变。`--show-panel` 启动方式在部分时序下搜索框不自动成为第一响应者，QA 时用 Tab 聚焦，不影响快捷键路径。

## 边界与后续

- 不加入剪贴板历史、剪贴板监听或后台网络。
- 单位换算不包含实时汇率/加密货币，因为没有离线可信汇率源；如后续加入，必须由用户显式触发并说明网络行为。
- 文件搜索仍使用全局输入和 Spotlight，不新增文件专用关键词，避免单字母前缀抢占应用搜索。
- 动作面板暂不含用户自定义动作、插件动作或脚本执行。
