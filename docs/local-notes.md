# 本地便笺

在启动器输入 `note` 或 `便笺` 查看最近便笺，追加关键字搜索标题和正文。搜索词未命中现有便笺时，首位直接提供「速记」动作：回车不打开窗口即可按时间戳追加到当日速记（`速记 · YYYY-MM-DD`），`⌘↵` 则新建独立便笺并打开。在空搜索框粘贴文本后，也可直接选择「追加到今日速记」或「存为新便笺」。启动器内选中任意便笺按 `⌘K`，支持直接复制纯文本、复制 Markdown、列表置顶或移入最近删除。已有网站/搜索引擎占用 `note` 时保持原配置，使用中文 `便笺` 进入。

便笺窗口采用统一的双栏工作台：左侧可收起侧栏（`⌘\`）支持即时搜索、置顶/最近分组、同窗口切换以及「最近删除」预览与恢复/彻底删除；右侧顶部支持直接内联编辑标题，并将「列表置顶」与「窗口悬浮置顶」拆开。收起侧栏并开启窗口置顶时，窗口最小尺寸可缩小至 `340 × 380` 作为轻量桌面悬浮便签使用；`⌘N` 新建独立窗口。

正文默认所见即所得，支持标题、粗体、斜体、删除线、列表、任务清单、引用、链接和代码块。输入 Markdown 快捷语法即可排版，也可切换到源码。当前格式不能无损表示为 Markdown 时源码只读；含外部图片、原始 HTML 或不支持表格的源码会提示修正，避免静默丢内容。

图片可粘贴、拖入或通过工具栏选择 PNG/JPEG/GIF/WebP，单张不超过 20 MB、3200 万像素。剪贴板 TIFF 会转换成 PNG。图片复制到便笺自己的附件目录，移动或删除原文件不影响显示；跨便笺复制图片也会复制附件。网络图片不自动下载，需要先下载后导入。

正文变化后约 350 ms 自动保存。失败显示错误并保留草稿；关闭、同窗口切换和退出前会再读取最新正文，保存失败、图片仍在导入或输入法仍在组词时会保留窗口。更正错误后点“重试”。此保护针对正常关闭，未确认的输入法内容与未完成的图片导入不能抵抗系统强制结束。

数据位于 `~/Library/Application Support/DontsTool/Notes/<UUID>/note.json` 与 `assets/`，删除项位于 `Notes/Trash/`。富文本 JSON 为权威，Markdown 和纯文本用于交换、导出和检索。正文离线运行，不加载 CDN、字体或远程图片；只有主动点击链接才交给系统打开。无历史版本或云同步。损坏/未来版本记录保留原文件并显示提示。

导出生成 ZIP，内含 `便笺/note.md` 和当前正文使用的 `assets/` 图片，使用相对引用，可以一起移动。未使用但仍可能被撤销操作引用的附件不提前清理，也不进入导出。

## 开发

编辑器源码位于 `Web/NotesEditor`。`make test-editor` 安装锁定依赖、运行行为测试并生成 `Resources/NotesEditor`。应用只使用生成的离线资源；普通 Xcode 构建不需要 Node，修改编辑器后须重新生成并连同源码提交。CI 检查生成产物一致性。

原生窗口与桥接在 `Sources/DontsTool/Shell/Notes`，Core 持久化在 `Sources/DontsToolCore/Notes`。编辑器资源通过限定当前便笺的 `donts-note://` scheme 访问，附件路径必须是该便笺自有 UUID 图片；不暴露通用文件读取。协议与编辑器限制见 [编辑器 README](../Web/NotesEditor/README.md)。
