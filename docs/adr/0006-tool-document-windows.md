# ADR 0006：工具使用独立具名工作窗口

- 日期：2026-10-18
- 状态：采用

## 问题

搜索结果行无法容纳持续编辑、检查完整结果和 JSON 对比。用户还需要同时处理多份 JSON，并通过标题识别它们。

## 决策

启动器只负责找到工具。每次明确执行 JSON、Base64、URL、时间戳、UUID、哈希或翻译入口，都会创建新的原生窗口。搜索刷新不创建窗口、不转换内容、不读写剪贴板、不发送翻译请求。

窗口按独立 UUID 管理，工具类型只用于分类。每个窗口拥有自己的 ToolDocument、ToolSession、原生编辑器及撤销历史；重命名不改变身份或处理状态。窗口内保留工具操作与命名，不增加自定义新建、复制和窗口列表。切换使用 macOS 自身的窗口管理。

Core 负责 JSON 精确解析、格式化、转义、结构比较、编码转换与会话状态。AppKit 管理 NSWindow、NSTextView、焦点与撤销，SwiftUI 呈现操作和状态。输入修订立即使旧结果失效，异步操作按版本发布结果。

草稿仅保留本次应用运行。关闭窗口保留最近 10 份可恢复草稿，退出不保存文本到磁盘；重新打开不会自动发起翻译。设置和密钥仍使用原有存储。

## 影响

应用/文件/网页搜索保留直接打开动作。文本工具不再以回车复制作为主交互；复制在工具窗口中明确执行。JSON 支持完整文本与错误定位，并保留大整数精度及字段顺序。UI 使用暖灰浅色与石墨深色工作区，原始 Stitch 导出和最终简化稿均在 design/tool-workspaces-v2 留档。
