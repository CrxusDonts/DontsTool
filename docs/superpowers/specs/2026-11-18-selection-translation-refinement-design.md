# 划词翻译：静默取词与词典释义

用户已明确要求：长按没有获取到文字时不弹翻译面板；单词需要按词性解释多个常见意思。

这是现有流程的小幅调整，沿用当前面板与纯文本译文，不增加词典服务或 UI 模式开关。

- 取词期间不新建或显示面板。失败、超时、纯空白只结束读取，并保留设置中的诊断，不发送翻译请求。
- 拿到有效文字后才显示面板与翻译进度。旧请求的取消和迟到结果保护继续生效。
- 未固定的旧卡片在新取词开始时收起；已固定的旧译文保持不变，直到新取词成功。
- 不再显示空卡片的读取/失败区域；有效选区的 API 配置和翻译错误提示仍保留。
- 单词及词汇性短语由模型按适用词性分组，覆盖常见的不同义项，必要时给简短用法和例句。不编造不存在的词性或强凑释义。
- 句子和段落仍按语境只返回译文，保留原有格式；输出使用目标语言和适合现有纯文本面板的换行。

验证：真实原生窗口的可见性、空白文本拒绝、固定卡片保留、取消与迟到结果、已有 Core/bridge 测试。词典效果如可使用现有服务则以无个人数据的固定单词核验；否则明确记录未进行真实模型验收。
