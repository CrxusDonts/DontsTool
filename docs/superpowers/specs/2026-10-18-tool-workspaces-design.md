# DontsTool 独立工具窗口重做

日期：2026-10-18

状态：用户于 2026-10-18 确认并要求开始实施；实现和验证进度见对应计划。

## 目标与范围

用户希望打开 JSON 工具后，获得一个可持续编辑、执行操作和查看结果的独立窗口，并将同样的体验扩展到已实现的 UUID、Base64 等工具。JSON 至少需要转义、去转义、对比。

本次将 JSON、Base64、URL 编解码、时间戳、UUID、哈希、翻译七类工具迁移到独立工作窗口。应用启动、文件搜索、网页搜索继续使用启动器里的直接动作。保留现有快捷键、设置、服务开关、翻译 API 配置和无第三方运行时依赖的约束。

成功标准：用户从启动器打开任意工具，能在窗口中完成一次操作、检查结果、修改输入再次操作、复制结果；整个过程不需要重新唤起启动器。处理错误不会丢失输入，也不会把旧结果误当成新结果。

## 方案选择

采用“每份工作内容一个独立窗口，共用窗口框架和编辑器”。同一类工具可以同时拥有多个具名窗口，各自持有会话。Base64 编码与解码属于同一工具类型，MD5/SHA1/SHA256 属于同一工具类型，但不限制该类型的窗口数量。2026-10-18 用户补充多份 JSON 并行与命名要求，并授权设计后直接实现；本节覆盖旧的单例工具窗口约定。

另两个考虑过的方向：把编辑器嵌进启动器，会受到短暂浮层、失焦关闭和面板尺寸限制；使用一个带侧栏的工具中心，可以集中导航，但切换工具和多工具并排处理会受同一窗口约束。独立窗口更贴合本次需求，也可复用当前 AppKit 窗口与 SwiftUI 内容的结构。

## 启动与窗口行为

- 空查询展示工具入口；支持中文名称、英文名称和关键词搜索。结果使用“JSON 工具”“Base64 编解码”等稳定标题，主动作统一为“新建窗口”。搜索时不执行转换、不读取剪贴板、不生成 UUID、不发网络请求。
- 保留 `json`、`b64`、`b64d`、`url`、`urld`、`ts`、`uuid`、`md5`、`sha1`、`sha256`、`tr`。带参数时，把参数送入对应工具，并选择该别名对应的模式。进入窗口后仍由用户执行操作。
- 参数前的分隔空格可以去除，参数内容的尾部空格、换行必须保留。无参数时新建空白窗口；已有窗口通过名称搜索或“窗口”菜单切换。剪贴板通过“粘贴”按钮或系统快捷键显式导入。
- 启动器执行工具入口或带参数入口总是创建新会话，已有内容不会被覆盖。搜索与选择过程不会新建窗口，只有明确执行才创建。点击已有窗口搜索结果仅激活对应窗口。
- 标准原生标题栏，支持拖动、缩放、最小化、关闭；失焦仍保留。默认内容尺寸 1040×700pt，最小 760×520pt。内容随窗口伸缩，工具栏可以折行或收进更多菜单。
- 工具栏提供图钉开关，每个窗口单独置顶；置顶使用原生 floating 层级，切换其他应用时不隐藏，再次点击恢复普通层级。新窗口默认不置顶，关闭后在本次运行中恢复同一草稿时保留置顶状态。
- 关闭后在本次运行中保留最近 10 个关闭窗口的标题、草稿和模式，支持“最近关闭”恢复。退出应用后清除文本草稿；本次不增加磁盘历史或自动保存。
- 打开工具时隐藏启动器且不恢复原应用焦点。延迟的启动器隐藏动画不得抢回新窗口焦点。关闭工具不退出菜单栏应用。
- `⌘N` 新建同类窗口；`⌘W` 关闭当前工具窗口；`Esc` 先处理当前弹层，不直接清空内容或关闭工具；文本输入中的回车正常换行。`⌘↩` 执行当前主操作，`⌘F` 搜索编辑区，系统复制、粘贴、选择和撤销均可用。

## 多窗口与命名

- 窗口拥有独立 UUID；标题只用于显示，重复标题不能导致窗口复用或串数据。自动标题按工具类型递增，例如“未命名 JSON 1”“未命名 JSON 2”。
- 标准标题栏显示“订单接口 · 测试 — JSON 工具”，保持原生拖动、最小化、平铺、缩放。重命名按钮与“窗口”菜单可打开就近的小型重命名浮层，不占编辑区域。
- 标题最长 80 个字符，去除首尾空白，空标题不提交；重命名不会改变输入、结果有效性或正在执行的操作。长标题截断显示，悬停可查看全文。
- 用户于 2026-10-18 进一步明确最简流程：唤起启动器 → 选择 JSON → 新窗口；再执行一次就再开一个。工具窗口不添加新建、复制、窗口列表等管理按钮。仅保留标题命名与 JSON 操作，窗口切换使用 macOS 原生“窗口”菜单和系统窗口管理。空查询不罗列已有窗口，避免挤占工具入口。
- JSON 对比两侧另有独立名称，例如“测试响应”“线上响应”，可以单独命名；左右名称与窗口标题不互相覆盖，交换左右时名称与内容一起交换。
- 每个窗口独立管理编辑器、撤销、光标/滚动、模式和异步任务。关闭一个窗口只取消它自己的任务；关闭后重开时恢复草稿，但不自动重新发起翻译。
- 底层文档草稿隔离且可独立恢复；不将复制窗口作为本次用户界面入口。
- 首个窗口居中，后续窗口错开位置；标题、最小化窗口和窗口列表可用于识别并排任务。不强制将独立窗口合并为应用内标签页。

## 共用界面与状态

窗口依次包含标题栏、工具专属操作栏、主要工作区、简短状态栏。JSON 编辑、Base64、URL 使用一个编辑区；JSON 对比和翻译按用途保留双栏，哈希与时间戳以紧凑卡片呈现结果；工具栏不重复添加无动作的大图标，不让装饰挤占编辑区。

通用编辑器使用 AppKit `NSTextView` 和 `NSScrollView`，桥接到 SwiftUI：等宽字体、行号、可选择文字、原生撤销、中文输入法、查找、可切换自动换行。关闭智能引号、智能破折号和自动文本替换。程序更新内容不得重置光标和滚动位置；高亮仅更新属性，不污染撤销历史或打断输入法组合。

原地操作直接更新当前文本，提供粘贴、清空与复制当前内容，不再需要“结果作为输入”。每次成功转换形成一条可撤销记录，⌘Z 恢复原文，重做只恢复文本、不重新请求转换。带独立结果的工具仍支持选中或按钮复制。空文本是合法的 Base64、URL 和哈希输入，不使用通用“空输入禁止执行”规则。

操作默认显式触发，不在每次按键后运行重计算。哈希、时间戳、翻译和 JSON 对比的输入或影响结果的选项变动后，旧结果保留并显示“输入已更改，需重新处理”，复制结果按钮禁用；重新成功执行后恢复。执行失败保留输入，显示就地错误，旧结果继续标明过期。提示包括可操作的原因，避免只弹一个转瞬即逝的 Toast。

耗时操作显示进度并允许取消。每次输入修订和任务均具有独立版本标识；只有输入、选项及任务仍匹配的完成结果才能更新界面。关闭窗口取消正在进行的任务。复制由明确按钮触发，操作完成不自动写剪贴板。

## JSON

### 编辑模式

仅保留一个全宽 JSON 编辑区。工具栏“格式化、压缩、转义、去转义”按钮直接执行并原地更新，⌘↩ 重复当前操作；复制复制当前编辑内容。格式化与压缩支持全部合法 JSON 根类型，包括对象、数组、字符串、数字、布尔和 null。

- 格式化默认两空格缩进，保留对象字段顺序。 引擎渲染最多 8 MiB UTF-8，原地替换前再校验 2 MiB 编辑上限，避免转换后超出下一次操作的输入限制；超限报错并保留原文。压缩只去除结构空白，不改变字符串内部空格或数字值。数字按原始词法保存，避免大整数或高精度小数被 Foundation 数值转换舍入。
- 转义：将输入区完整文本编码为一个 JSON 字符串字面量，输出包含外层双引号，正确处理引号、反斜杠、控制字符和换行。该操作不要求输入本身是合法 JSON。
- 去转义：提供“完整 JSON 字符串”和“无外层引号”两种明确输入方式，默认前者。完整模式要求输入是 JSON 字符串值；无外层引号模式按 JSON 字符串内容规则解码。均只解码一层，禁止循环解码、猜测修复和 JavaScript eval。
- 解析错误显示原因、行、列，并可定位到输入位置；不把截断文本视为成功。
- 当前编辑内容具备 JSON 语法高亮。成功处理后更新当前内容，不擅自排序字段；错误、取消或草稿发生变化时不替换原文。

### 对比模式

切换到“对比”后显示“左侧 JSON”和“右侧 JSON”两个可编辑区域，下方为差异列表。编辑模式与对比模式各自保留内容，切换不覆盖草稿；提供将当前编辑内容送到左侧或右侧的明确操作，替换可以撤销。

点击“对比”后执行结构比较：对象忽略字段排列，数组按索引比较，区分字符串/数字/布尔/null 类型；数值按精确十进制值比较，`1` 与 `1.0` 相同，超出浮点精度的大整数仍能区分。新增、删除、修改分别标识，同时给出路径、旧值、新值。JSON Pointer 路径正确转义 `~` 和 `/`，数组使用数字索引；根值变化显示“根节点”。

选择差异项定位对应侧的文本范围并高亮；单侧不存在的字段只定位存在的一侧。差异同时使用文字和符号说明，不只依赖颜色。展示新增、删除、修改数量和“无结构差异”；任一侧错误都显示所属侧的错误位置，不给出虚假的相同结论。

对比拒绝重复对象键，并定位重复位置，避免把被覆盖的值隐藏在“无差异”里。普通格式化和压缩同样拒绝重复键。

为保证可用性，每侧 JSON 最多 2 MiB UTF-8、嵌套深度最多 256；超限给出清楚提示，不截断处理。对比计算完整数量，差异列表最多显示前 1000 项，并明确展示总数与显示数量。解析、格式化和对比离开主线程执行，任务取消或版本变化后不再发布结果。

## 其他六类工具

| 工具 | 工作区与操作 | 关键规则 |
| --- | --- | --- |
| Base64 | 单编辑区，编码／解码直接原地执行、复制当前文本、撤销 | UTF-8 文本；标准 Base64，另提供 URL-safe 开关；解码允许换行及空白、允许省略末尾 padding，但拒绝其他非法字符；解码为非 UTF-8 数据时明确说明本工具处理文本 |
| URL | 单编辑区，编码／解码直接原地执行、复制当前文本、撤销 | 编码一个 URL 组件，保留 RFC 3986 未保留字符；默认不把 `+` 当空格；提供独立“表单模式”，明确改变空格/加号规则；非法 `%` 序列或无效 UTF-8 显示错误 |
| 时间戳 | 输入区下方紧凑展示秒、毫秒、日期三行，支持单行／全部复制 | 时间戳自动识别只用于 10 位秒/13 位毫秒；其他位数明确选择单位后接受合法数值，包括负数；日期严格解析，结果展示秒、毫秒、带时区日期；“当前时间”按钮显式刷新，不持续跳动 |
| UUID | 数量、大小写、保留连字符开关，生成、逐行结果、单条/全部复制 | UUID v4；数量为 1–1000 的整数；首次打开生成一条，搜索与窗口重聚焦不再生成；只有“重新生成”替换已有结果，显示本次条数 |
| 哈希 | 多行文本输入，下方紧凑展示完整哈希值，MD5/SHA1/SHA256 选择、计算、复制 | 按 UTF-8 精确计算，包括空白和尾部换行；别名决定初始算法；结果完整显示；不混入密码加密文案 |
| 翻译 | 原文/译文双栏、目标语言选择、翻译/取消、复制译文、打开设置、网页翻译 | 继续使用现有 API 与 Keychain 配置；只有点击翻译才发送原文；未配置时说明缺少配置并能打开设置；网页跳转由独立按钮触发，带上当前原文和目标语言；失败保留原文并支持重试 |

Base64 与 URL 不自动切换方向；点击编码或解码即处理当前文本，每次操作都可撤销。原地操作只有在任务、输入版本和结果大小均有效时才提交到草稿；2 MiB 以上的处理结果不覆盖当前文本。

文本编码和哈希输入限制为 2 MiB UTF-8，超限就地提示。翻译文本长度上限沿用配置服务的实际错误响应，不假设所有自定义 API 具有相同额度。

## 代码边界与迁移

1. Core 新增稳定的工具标识、入口定义和打开请求（工具、初始模式、可选输入），以及可替换的打开协议。`TextToolsProvider` 和 `TranslationProvider` 返回打开请求动作；从搜索过程移走计算、剪贴板写入与异步翻译。
2. App 负责依赖组装：窗口管理器按独立 UUID 持有窗口和会话，工具类型仅作为分类；现有剪贴板、翻译服务、设置、URL 打开器通过注入复用。
3. Shell 新增工具窗口控制器和通用原生编辑器；为动作增加明确的窗口交接语义，避免 `.dismissThenRun` 默认恢复旧应用。只修改此次窗口交接涉及的生命周期，不改动双击 Option 实现。
4. UI 按工具分离视图和状态模型，共用编辑面板、状态、复制和错误组件；JSON 结构解析/差异、文本转换、UUID 生成放在可单测的 Core，不放入视图回调。
5. JSON 解析结果保留节点源范围、数字词法和字段顺序，统一供格式化、定位及对比使用。旧 `formatJSON` 入口可委托新实现，消除顶层标量和精度问题。
6. 更新 README、架构文档和旧设计中已经被本次交互替代的说明，区分真实实现与历史 HTML 设计稿。

现有文本服务开关控制对应入口；翻译开关独立。已打开的工具窗口在服务被关闭后仍可完成当前编辑，启动器不再提供新入口。

## 验收与验证

- 每类工具可由名称和别名打开；打开动作只交接窗口，不自动复制。含空白的编码/哈希参数传递不失真；同工具的多次明确打开创建独立窗口，单纯搜索刷新不新建窗口，原有草稿不会被覆盖。
- JSON 覆盖根标量、非法输入行列、Unicode、换行/反斜杠、多层转义仅解一层、重复键、大整数、指数数字、字段顺序、数组位置、类型差异和 JSON Pointer 特殊字符。验证格式化/压缩不改变值。
- Base64 覆盖中文、空输入、换行、padding、URL-safe、非法字符和非 UTF-8；URL 覆盖中文、空格、加号、百分号与两种模式；哈希使用已知摘要并验证尾部换行有影响。
- 时间戳用固定时间和时区验证秒/毫秒、负值、非法日期及带偏移 ISO 日期；UUID 验证版本/variant、数量边界、显示选项与显式重新生成。
- 模拟翻译成功、未配置、错误、取消，以及任务结束前原文/目标语言修改，保证旧响应不能覆盖新输入对应的界面。
- 原生界面核验：七种窗口、同工具多开与命名、同名窗口独立身份、多工具并存、输入/结果复制、撤销、中文输入法、查找、缩放、深色模式、关闭重开草稿、启动器焦点交接与 `⌘W`。
- 执行完整单元测试和 Debug/Release 构建；大型 JSON 操作检查主线程可交互和取消有效。外部翻译真实服务仅在用户已有有效配置且明确触发翻译时调用，模拟响应验证与真实联网验证分别记录。
