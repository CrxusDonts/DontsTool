# 本地便笺

用于研发随手记录文字、代码和图片。用户确认默认所见即所得，支持 Markdown 输入快捷方式；图片粘贴后必须由便笺管理，不能引用原图片路径。

## 交互

- `note` 显示新建入口和最近便笺；`note 关键词` 在本机检索标题与正文。全局仅提供便笺入口。已有快捷词冲突时保留原配置，中文“便笺”入口仍可用。
- 单栏编辑窗口，沿用现有深浅色 UI。支持标题自动取首行、手动重命名、置顶；同一篇聚焦已有窗口，不同篇可多开。
- 标题、段落、粗斜体、删除线、引用、有序／无序／任务列表、代码块、链接和图片；Markdown 快捷输入与源码切换。
- 截图直接粘贴、拖入常见图片或从文件选择器插入，图片就地显示。异步导入须保留插入位置；失败提示，不插入坏链接。复制已有便笺图片到另一篇时复制附件所有权。
- 自动保存，明确显示保存中／已保存／失败。关闭或退出前取得最新正文并落盘；失败保留窗口，不静默丢稿。删除移入应用内最近删除，可恢复。
- 导出 Markdown 与正在使用的图片附件为可携带的文件包；不导出已移除图片。

## 存储与边界

每篇以稳定 UUID 建独立目录，`note.json` 原子保存版本化正文、Markdown 投影与元数据，`assets/` 保存拥有的图片。编辑正文以富文本 JSON 为权威，避免 Markdown 往返丢失；相对图片引用保持不变，标题修改不移动目录。无云端同步。

离线打包的编辑器通过 WKWebView 承载；原生壳负责文件、附件、保存和窗口。自定义 scheme 仅开放当前便笺的有效附件与打包资源；禁止任意文件读取、远程图片、脚本和隐式网络请求。外部链接仅由用户主动点击后交给浏览器。

图片先验证与保存，再插入正文；限制字节数与像素尺寸。删除正文图片不立即销毁附件，保证撤销；导出只收集当前正文引用。损坏或未来版本文档保留原始文件并提示，不自动覆盖。
