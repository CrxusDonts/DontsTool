# 文件搜索超时与输入法组合态

用户报告多次文件搜索超时，并要求中文输入法尚在组词时不触发搜索。

当前代码使用 120ms 防抖和 300ms Spotlight 硬上限。本次真实 mdfind 采样为 37–132ms，没有复现历史超时现场；确定复现了 500ms 查询被截断、取消被误报、忽略终止信号的进程未及时退出。

- 保留 120ms 防抖，将文件查询硬上限放宽到 2 秒。正常完成立即返回，超时仍展示已取得的部分结果。
- 输入变更和中文组词开始时，取消旧查询。取消不是文件服务错误，不污染新查询状态。
- 查询进程先接受正常终止，200ms 后仍未退出则强制结束；已取消任务不启动新进程。
- 以 AppKit 的真实 marked text 状态为准，组词期间不搜索。开始组合时清除旧查询及旧可执行结果，提交文本后重新开始 120ms 防抖。
- 候选词中的方向键、回车和 Esc 交给输入法，不触发启动器操作。unmarkText 和 insertText 两种提交路径都能触发最终查询。
- 保留文件名索引、用户目录范围、完整路径打开和文件搜索开关，不重建 Spotlight 索引。
