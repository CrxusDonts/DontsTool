# 可配置搜索引擎

每个引擎配置稳定 ID、名称、快捷词、带 `{query}` 的 HTTP(S) 网址模板、启用状态。内置 Google、必应、百度、DuckDuckGo、GitHub 作为可编辑初始配置；保留旧默认引擎选择。

唤起方式：`快捷词 搜索内容` 直接打开对应搜索页；只输入快捷词显示引擎和输入提示，回车补全快捷词及空格。全局搜索可按引擎名称找到入口；普通查询保留默认引擎回退。保存后立即更新路由。冲突快捷词不得静默失效。

设置的“搜索”页提供手动增删改、启停、默认选择和 JSON 全量编辑／复制导出。沿用现有原生样式。保存统一校验，错误不覆盖旧配置；损坏配置保留原文供修复。关键词按 UTF-8 编码，不改变既有参数，也不作为网址结构解释；占位符仅允许在路径、查询和片段中。

网址分组已有的 `gh` 接管规则保留；其他网址快捷词和搜索快捷词冲突时明确拒绝保存。只在用户执行打开动作时交给浏览器。
