# 启动器应用历史口径修正

用户明确要求“最近打开的应用”指从 DontsTool 启动器打开的应用。

- 移除系统应用激活通知对使用记录的写入。
- 仅在应用结果的「打开」动作成功后，记录一次启动器使用并更新时间。打开失败、复制路径、在访达中显示和退出不累计。
- 最近排序只展示有启动器打开记录的应用，按最后一次成功打开时间倒序，最多四个；输入搜索仍能找到从未通过启动器打开的应用。
- 频率和名称两种排序模式保持现有范围与逻辑。
- 旧数据的零次数应用来自系统激活，迁移时移除。已知启动器打开次数保留，但其时间混入了系统切换，重置为未知的最早时间；最近列表暂不展示未知时间的项目，下次从启动器打开后重新进入列表。
- 迁移一次性执行，保留网址和文件历史，并确保重新启动不会清掉新记录。

用真实记录迁移、排序、成功和失败动作回归测试验证；不为最近应用列表监听或统计 Dock、访达、Cmd-Tab 的应用激活。
